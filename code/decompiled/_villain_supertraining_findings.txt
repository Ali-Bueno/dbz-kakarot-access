GOTCHA FOR FUTURE PROBES
------------------------
A UFUNCTION name for which `ufunc` finds no table row is most likely a BlueprintImplementableEvent
(no native exec at all). Tell: `str NAME` lists one ASCII copy per declaring class, each referenced
only from UFunction construction code in 0x1401xxxxx-0x1402xxxxx. Do not spend runs hunting its
impl. (villain_probe.java also drops dragonball_probe's NUL-before-name check and counts only
valid hits toward the 40 cap; harmless, since the exact table-pointer match keeps names exact,
but it was NOT the cause of the empty DetailUpdate result.)
